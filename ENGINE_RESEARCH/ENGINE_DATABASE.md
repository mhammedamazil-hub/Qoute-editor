## Notes on the table

- *Licence (verified text)* is what the file or README states. *Licence class* is a grouping by that text. Only the 'OSI' labels are a grouping, not a certification.
- *Source-available* projects (CRYENGINE mirror, Flax, Defold) are not open source by their licence text, and are not treated as open source anywhere in this folder.
- Last-push dates are copied from the API responses in `SOURCES/meta/`, unchanged. Some are later than the session date (2026-11-19 UTC). The fetch time is not recorded in the stored files, so this is reported as returned, not explained.
