# PHYSICS

Contents:
- `collision_solver_review.md`: targeted source review of Box2D, Rapier, ReactPhysics3D, Jolt, cannon-es and Chipmunk2D,
  with MuJoCo taken from the Phase 7 review. Covers broadphase, manifold size and reduction, solver defaults, warm starting
  and CCD. Facts (with file and line), comparison with Reality, hypotheses, and what was not covered.

Method limits, stated once: the source trees are the default branches downloaded on the day of the review (commit SHAs in
`SOURCES/SOURCES.md`). The reviews read the named files only. No physics was run in the other engines, so no accuracy or
speed claim is made here.
