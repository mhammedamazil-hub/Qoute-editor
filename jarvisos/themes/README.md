# JARVISOS themes

- `Jarvis-Dark/gtk-3.0/gtk.css` → `/usr/share/themes/Jarvis-Dark`
  (flat dark + cyan; no expensive gradients for weak iGPUs).
- `Jarvis-Dark/openbox-3/themerc` → window decorations.
- Icons: Papirus-Dark (Debian package, no custom icon work needed).
- Boot: `boot/plymouth` + `boot/grub-theme`; wallpaper is generated by
  `scripts/make-wallpaper.py` into
  `filesystem/usr/share/backgrounds/jarvis-default.png`.
