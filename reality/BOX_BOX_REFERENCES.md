# Box–box collision: references and verification status

Only sources listed here are relied on for Phase 7. Each entry records how it was obtained and what was verified. "Read"
means the text or code was read in the sandbox. "Excerpt" means only a search-engine excerpt was seen. "Not read" means the
source is listed for context and is not used for any claim.

Digests are SHA-256 of the archives downloaded from `codeload.github.com` during the research (reproducibility).

---

## Primary sources

### R1. Gregorius, D. — *Robust Contact Creation for Physics Simulations*, GDC 2015 (Valve)
- URL: http://media.steampowered.com/apps/valve/2015/DirkGregorius_Contacts.pdf (also listed at valvesoftware.com/en/publications)
- Obtained: fetch tool, 2 chunks, the second marked as the end of the document.
- **Read.** Used for: contact point, normal and depth definitions; manifold as points with a common normal; stable manifold
  (centre of mass inside); one-shot manifold by SAT followed by clipping one feature against the side planes of the other;
  the four-point assumption.
- **Not verified:** the reduction method and the "contact optimizations" section, which the extracted text does not contain.
  Not used for any reduction claim.

### R2. Eberly, D. — *Dynamic Collision Detection using Oriented Bounding Boxes*, Geometric Tools, LLC
- Canonical URL: http://www.geometrictools.com/Documentation/DynamicCollisionDetection.pdf
- Mirror seen in a search result: https://www.cse.iitk.ac.in/users/amit/courses/RMP/presentations/dslamba/presentation/dynacoll.pdf
- Obtained: the canonical URL and the mirror both failed to fetch (sandbox fetch tool and network allow-list). The search engine
  returned excerpts.
- **Excerpt only.** Used for: "There are 15 potential separating axes: 3 for the independent faces of the first OBB, 3 for the
  independent faces of the second OBB, and 9 generated by an edge from the first OBB and an edge from the second OBB."
- **Not verified:** the proof of completeness, the parallel-edge handling, and any formula in the paper. The mathematics
  document derives its own formulae and tests them against an independent oracle.
- Year: the search results give 2008 (Geometric Tools) and one record gives 2016 (Semantic Scholar). The year is therefore
  not asserted.

### R3. Box2D v3 — `src/manifold.c` and `LICENSE` (Erin Catto)
- Source archive: `https://codeload.github.com/erincatto/box2d/tar.gz/refs/heads/main`
  - SHA-256 `c2a1fcdb51ca8d4bff21b7d4b5c578ab6bfbc8c51f3e56df220d8a12e49ef00d` (file `box2d.tgz`)
- Licence: **MIT**, read from `LICENSE` ("Copyright (c) 2022 Erin Catto"). A header in `include/box2d/b2_collision.h` gives 2019;
  the `LICENSE` file is the authority cited here.
- **Read.** Functions: `b2ClipPolygons` (line ~515), `b2FindMaxSeparation` (line ~650), `b2CollidePolygons` (line 769).
  Used for: the reference/incident choice (incident edge = minimum dot against the reference normal), the 2D clip against side
  planes, midpoint contact points with radius correction, and the disjoint-edges fallback to closest points.
- **Not copied.** The algorithm is 2D. The 3D method is derived in `BOX_BOX_MATHEMATICS.md`.
- Limitation of the reading: the code was read, not run; no Box2D behaviour is claimed beyond the code text.

### R4. MuJoCo — `src/engine/engine_collision_box.c` and `LICENSE` (Google DeepMind)
- Source archive: `https://codeload.github.com/google-deepmind/mujoco/tar.gz/refs/heads/main`
  - SHA-256 `38ebc2ef03b39712bca0207d04ce7d776f19579ed7ae53c1106f71999c94cf91` (file `mujoco.tgz`)
- Licence: **Apache-2.0**, read from `LICENSE`. The file header says "Copyright 2016 Svetoslav Kolev".
- **Read in full:** `mjraw_BoxBox` (lines ~698–1066), `clipHalfPlane` (~656), stage comments (605–614) and constants (615–646).
  - Stage 1: the 15-axis test with support radii from `|R_ij|`; a separation tolerance that carries rounding slack; the
    edge-axis skip when `‖A_i × B_j‖²` is below a threshold.
  - Stage 2a: edge contact as the midpoint of the closest pair of two clamped supporting edges, depth along the axis.
  - Stage 2b: face contact; the incident face is the one least aligned with the reference normal; clipping against four side
    planes; every vertex in the margin band kept.
- **Constants recorded, not adopted** (their values are tied to their own precision and margin model): `SEPEPS`, `PAREPS`,
  `SGNEPS`, `DUPEPS`, `EDGEBIAS = 1e-6`, the 5 % face-substitution rule, and the 0.99 face-dot threshold.
- **Development oracle:** the PyPI package `mujoco` 4.0.1 (installed in the test venv, outside the workspace). The
  source archive's `main` branch and the 4.0.1 wheel are different versions; claims about behaviour are made only for the
  wheel, which was executed (probe in `BOX_BOX_RESEARCH.md` §4.4).
- The PyPI metadata field for licence is empty; the Apache-2.0 licence applies to the source archive read.

### R5. Bullet Physics — `src/BulletCollision/CollisionDispatch/btBoxBoxDetector.cpp` and `LICENSE.txt`
- Source archive: `https://codeload.github.com/bulletphysics/bullet3/tar.gz/refs/heads/master`
  - SHA-256 `47aa243bc6862f1d59c3b7c85f17d2c7a33dc52c2f9a7d225185c2e1475fb469` (file `bullet.tgz`)
- Licence: **zlib**, read from `LICENSE.txt`. The source file header: "Box-Box collision detection re-distributed under the ZLib
  license with permission from Russell L. Smith. Original version is from Open Dynamics Engine, Copyright (C) 2001,2002
  Russell L. Smith."
- **Read:** `dBoxBox2` (lines 272–728), the `fudge_factor = 1.05` axis-preference macro (line ~278, ~363), `cullPoints2`
  (line ~188) and its use when more points are generated than `maxc` (line ~700).
- **Recorded as a contrast:** the cull is a selection heuristic seeded at the deepest point, so it discards points.
- The original ODE licence was **not** read and is not cited.

### R6. Sutherland, I. E. & Hodgman, G. W. — *Reentrant Polygon Clipping*, Communications of the ACM 17(1), 1974, pp. 32–42

  Polygon Clipping. 32-42" (https://www.sigmod.org/publications/dblp/db/journals/cacm/cacm17.html).
