## How to read this report

Each case compares a solver with a reference: an analytic closed form, a textbook result,
a separate numerical method, or a conservation law. *Measured error* is the relative error
(absolute error when the reference is 0). A case passes when the error is below its tolerance.

Kinds of check:

- `analytic` / `textbook`: solver output vs closed-form or published value.
- `numerical-vs-analytic`: time-stepping or discretised solver vs exact solution.
- `conservation`: an invariant (momentum, energy, angular momentum, Stefan balance) is preserved.
- `database`: data-integrity checks on the material database.

Some `analytic` cases verify algebra (for example an identity such as R + T = 1). They confirm
the implementation of a formula, not that the formula describes a real system. Physical
validity still depends on the model assumptions listed in `PHYSICS_MODELS.md` and `LIMITATIONS.md`.
